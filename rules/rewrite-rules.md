# 核心改写规则（八大手法 + 两条全局法则 + 句式模板转换表）

> 本文件是本技能的操作核心。改写时逐段执行，每段过完八大手法与全局法则再进入下一段。
> 示例为虚构领域文本；改写手法与路线参数来自实测校准（战绩见 README）。
> 拿不准某处怎么改时，问一句：**"这么改，文本离'真人论文语料'更近，
> 还是离'漂亮文字'更近？"** 更近论文语料 → 执行；更近漂亮文字 → 不执行。

## 手法一：虚词密度对齐（最重要）

真人论文语料的"的、了、是、在"密度显著高于 LLM 文本。改写时按以下原则对齐：

- **"的"字自然落点，不刻意堆但要有下限**：同词重复、零修辞、长句为主这些统计特征
  方向照走，但"的"字不是 KPI——该有有、不该有没有，密度是结果不是目标。
  原文"的"少就自然加（八股句式"是…的"、框架句"在…方面"），但绝不堆砌。
  全文密度落在 0.045～0.065 属最佳区间，0.03～0.09 均属正常范围。
  **密度低于 0.04 时必须补**：深度重组后如果密度自然偏低，用八股句式
  （"是…的""在…方面"）把密度撑到 0.045 以上——PaperPass 对低密度敏感
  （v1.4.7_2 实测：密度 0.033、深度重写率 0%，AIGC 81.08% 未降）。
  唯一禁止的是"为凑密度而拗口"
- "了"字收尾多用："老年人口是越来越多了，到了现在已经超过2.9亿**了**"
- "是…的"判断句多用："业务范围**是**以国内为主**的**""这种服务方式**是**容易接受**的**"
- "在…方面 / 在…上"框架多用："**在**这个基础上再去搭建统一的调度平台"

**删短语不删虚词（边界，盯死）**：冗长的短语结构可以拆
（"由于…的事实"→"因为"），但"的、了、是、在"是统计特征，一个不许动。
删任何东西前先自问：删的是短语，还是虚词？

**反例（什么时候停手）**：连续三个"的"堆叠（"院区的老人的实时的状态"）
即调整句式——双"的"并列是刻意保留的人类语料特征，三连"的"是磕巴；
同段密度已超 0.07 且读着拗口时，优先删新加的"的"而不是继续堆

## 手法二：同词大方重复（反直觉，必须执行）

LLM 有"换词避重"天性（同义词循环），检测器把换词当成 AI 签名。
真人写论文大大方方重复用同一个词。**严禁同义词循环。**

**示例：**

- ❌ 主管**拿它**做排班；护理员**带它**去查房；家属**将它**用于联络（三种说法 = AI 签名）
- ✅ 主管**用于**日常排班的管理；护理员**用于**老人巡访的工作；医生**用于**医养协同的环节；家属**用于**远程关注与应急联络的需求（"用于"×4，重复执行）

并列结构里，同一框架词连用 3～4 次是加分项，不是毛病。

**保留反例（什么时候别用）**：同词重复放在分句之间，不放同一个句子
内部——一句之内"漏诊率的漏诊率"式撞车禁；原文本来就是自然重复的
（人工撰写稿本来就同词连用），不是 AI 换词避重，不必动

## 手法三：长句流水化（禁刻意交错）

真人论文多长句：一个句号内 3～5 个逗号分句串到底。改写时合并碎句、拉长逗号链。

**禁刻意长短交错**：为了"节奏感"故意一句长一句短，是 AI 改写工具的节奏签名，
检测器认得出来。目标形态是论文语料的均匀流水长句，不是抑扬顿挫的散文。

- ❌ 护理员招不来，也留不住。（短句对仗 = 精致 = AI 形态）
- ✅ 招不到人、留不住人，成了养老行业多数的机构现在都要面对的问题。（流水到底）

- ❌ 全域化是绕不开的方向。（金句短收 = AI 形态）
- ✅ 健康监测的技术正在从单点采集向全域联动的方向发展。（平铺直叙）

**保留反例（什么时候别改）**：原文长句本身通顺的保持原句，只做轻量
形态调整；拉长到粘连病句（主干迷失、一口气读不下来）即停——
目标是论文语料的"通顺的笨"，不是磕巴的笨

## 手法四：论文八股句式库（放心连用）

以下句式在真人论文语料中高频出现，检测器视为人类特征，可重复使用：

- "从…来看 / 从…的层面来看"
- "在…方面有…"
- "…是没有问题的"
- "对…是有帮助的 / 是有价值的"
- "…也就具备了"
- "在这个基础上再去…"
- "采用了…的方式"
- "主要包括了…"
- "把…放在了…上"

八股不是缺点，是保护色。宁可笨，不可巧。

**保留反例**：八股句式一段连用一两处即可，连用三次以上主动换朴素直陈
——全文清一色八股会形成新的模板感，八股是保护色不是地基

## 手法五：列举节奏破坏

AI 爱写四字工整并列（"跌倒预警分析、睡眠质量监测、用药提醒复核"）。
给每个并列项插"的"或补成偏正结构，破坏工整节奏：

- ❌ 跌倒预警分析、睡眠质量监测、用药提醒复核、异常行为识别
- ✅ 跌倒**的**预警分析、睡眠质量**的**监测、用药提醒**的**复核、异常行为**的**识别

三项并列（三段式）是典型 AI 签名。处理顺序：先按上法插"的"破坏节奏；
**仅当并列项是无信息量的拔高词（"提质增效""赋能"类套话）才可砍项**。
并列项有实义信息（功能名、需求名、对象名）的，一律保留全部项，**禁止删项**
——论点丢失是信息事故，不是改写手法（红线见 rules/safety-lines.md 信息保全红线）。
顿号 / 分号的平铺列举本身是真人论文高频形态，保留，别拆散。

## 手法六：平滑连接词拆除

以下连接词是 AI 高频签名，拆除或替换成论文八股过渡：

| AI 连接词 | 处理方式 |
|---|---|
| 因此 | 拆句，或"从这个层面来看" |
| 同时 / 与此同时 | 拆成两个独立句，或"在…方面" |
| 此外 | 直接删，另起句 |
| 不仅…还… | 拆成两个平铺句 |
| 从而 | 改"…也就具备了"或拆句 |
| 综上所述 | 改"从以上几个方面来看" |

**拆除边界：保留 2 ～ 3 个学术连接词**。全拆光会从"AI 腔"倒向"博客腔"，
评阅观感差。拆"因此 / 此外 / 综上所述"这类 AI 高频签名的同时，
保留"鉴于""二者""与之相反"等不在 AI 高频表内的学术连接词，
每段至少留 1 个、全文保留 2 ～ 3 个类型

## 手法七：术语句法位置挪动（术语一字不动）

LLM 倾向把术语放在主语位置，真人更常放在宾语或话题位置。
**术语本身一个字不动，只挪动它在句内的语法角色**：

- 术语居主语位 → 挪到宾语位或话题位（"X 显著提升了 Y"
  → "对 Y 产生显著提升作用的是 X"，术语 X 原样保留）
- 学科共识词（互补效应、固定效应、中介效应、稳健性检验等）原样保留，
  严禁替换成口语说法、严禁加引号造距离感
- 认知来源：知网第三方实测画像（记录见 references/detector-profile.md）

## 手法八：深度句式重组（降率主引擎，必须执行）

统计形态铺设（手法一～七）让文本"长得像人写的论文"，但检测器还看句式结构。
如果只换词不动结构（"快速发展"→"扩张速度很快"），检测器算出来还是同一棵句法树。
**深度句式重组 = 句法结构级重写**，不是同义替换——改变句子的语法树形状。

实测依据：aigc-reduce 低密度（0.032）但 59 句中 50 句做了结构级重写，PaperPass 降到 28%；
v1.4.7_2 密度 0.033 但 52 句中 0 句做结构级重写，PaperPass 81.08% 未降。
**降率的差异不在密度，在结构重写率。**

### 操作清单（每句至少做一项，全文 80%+ 句子要动结构）

| 操作 | 说明 | 示例 |
|---|---|---|
| 主被动换位 | 主动句↔被动句，主语宾语对调 | "法院认定了劳动关系" → "劳动关系被法院所认定" |
| 拆句 | 一句拆成两句，打断句法树 | "分歧集中在从属性、算法控制和报酬支付三个要件上" → "分歧集中在三个要件上。其一是从属性强度，其二是算法控制程度，其三是报酬支付方式" |
| 合句 | 两句合成一句，改变分句结构 | "多数法院仍把传统从属性标准当作核心判断依据。考察重点是考勤管理。" → "多数法院仍把传统从属性标准当作核心判断依据，考察的重点则放在了考勤管理上" |
| 语序调整 | 状语前后移、宾语前置、因果倒装 | "由于现行规范没有明确界定，各地法院裁判结果差异显著" → "各地法院在裁判结果上的差异之所以显著，原因之一在于现行规范没有作出明确界定" |
| 句式变换 | 判断句↔陈述句、主题句↔评论句 | "这一分布说明否定劳动关系是主流" → "从这一分布来看，否定劳动关系在当前裁判实践中是主流的做法" |

### 约束（红线，与 safety-lines.md 信息保全一致）

- **数字、术语、结论逐字锚定**：结构可深，信息不漂——改完逐句核对信息点
- **论点一个不少、一个不新增**：重组是换句法树不是换内容
- **不改变因果/逻辑关系**：可以倒装语序但不能反转因果
- **不引入新信息**：拆句拆出的是原文已有的信息，不是新论据

### 判定标准

- ✅ 结构级重写：句法树形状变了（主语/宾语/状语位置改变、句子被拆分/合并）
- ❌ 非结构级：只换词（"快速"→"迅速"）、只删虚词、只调标点——这些不算深度重组
- **目标：全文 80%+ 句子做结构级重写**，check_patterns.py 第 15 维可量化检测

## 全局法则一：引号格式（全文执行）

中文正文一律使用全角弯引号""、''，**禁止 ASCII 直引号包中文**。
中文正字法本身就是人类语料特征，ASCII 直引号包中文是机器与翻译腔的痕迹。
改写时顺手把原文残留的直引号全部换掉。

## 全局法则二：口吻边界（全文执行）

- **可用**的第一人称："本文""笔者""本项目""我们认为"
- **不用**的口语个性："说实话""讲真""我真的不知道该怎么看"这类博客式表达
- 理由：真人论文语料的个性密度低，口语化个性表达会拉大文本与人类论文分布的距离。
  论文要的不是"有灵魂"，是"像论文"。

## 句式模板转换表（速查）

| AI 句式（要消灭） | 论文语料句式（改成） |
|---|---|
| 主语 + 越来越 + 动词 | "如今愿意…的 + 对象 + 是越来越少了" |
| 话题前置短句（"跌倒检测，毫米波雷达是现成的"） | "跌倒检测方面有毫米波雷达的方案" |
| 三项并列 A、B和C | 插"的"破坏节奏保住全部项；仅无信息量拔高词可砍（见手法五） |
| 四字工整并列 | 偏正结构展开（见手法五） |
| 金句收尾（"大有可为"） | 朴素判断（"对拓宽…的应用场景是有价值的"） |
| 换词避重（拿它/带它/将它） | 同词连用（用于×4，见手法二） |
| 破折号插入语 | 改逗号分句 |
| 成语（摇身一变、顺理成章） | 朴素动词（变成了、在这个基础上） |
| 口语词（搭把手、省心、路子） | 书面朴素表达（辅助、降低门槛、方向） |
| 修辞设问（"为什么护理员留不住？"） | 删除，直接陈述 |
| "作为…的体现 / 见证了…的…" | 直接说事实是什么 |
| 模糊归因（"专家认为""行业报告显示"） | 保留原意但降调（"行业调查的数据显示"），不得编造具体出处 |
| 尾缀式肤浅分析（"…，确保了…，反映了…"） | 拆成分句，删尾缀 |
| 宣传腔（"充满活力的""令人叹为观止"） | 删，换朴素限定语或直接陈述 |
| 来源堆砌（"被XX、XX和XX引用"） | 删堆砌，留一条具体来源或删 |
| 虚假范围（"从X到Y"） | 拆成具体列举 |
| 通用积极结论（"未来可期"式收尾） | 删除，或换成具体计划 |
| 过度限定（"可以潜在地可能被认为"） | 直接说 |
| 粗体强调 / 内联标题式列表（**X:** …） | 拆成连贯正文 |
| 术语居主语位（"X 显著提升了 Y"） | 术语挪宾语/话题位（"对 Y 产生显著提升作用的是 X"） |
| emoji | 删除 |
| 聊天残留 / 免责声明 / 谄媚语气 | 删除 |
| 只换词不动结构（"快速"→"迅速"） | 结构级重写（主被动换位/拆合句/语序调整，见手法八） |

## 每段改写完的自查清单

1. 有没有强行堆"的"——一段读着拗口且密度超过 0.07，检查是不是堆出来的？堆的删掉
2. 有没有成语、口语词、破折号残留？
3. 有没有不自觉的同义词循环？一句之内有没有同词撞车？
4. 并列项是否还保持四字工整？有没有连续三个"的"堆叠？
5. 引号是否全部为全角弯引号（无 ASCII 直引号包中文）？
6. 口吻是否守住论文边界（无博客式口语个性表达）？
7. 事实、数字、专名与原文逐字核对过了吗？
8. 有没有"X 的 Y 的 Z"三层名词嵌套？（有则拆一层）
9. 原文信息点清单逐条比过了吗（论点一个不少、一个不新增）？
10. 全文是否还保留着 2～3 个学术连接词？
11. **深度重组率够不够**——80%+ 句子的句法树形状变了吗？还是只换了词？
    拿不准时抽 10 句和原文对比，结构没变的回去重改（check_patterns.py 第 15 维可量化）
12. 密度是否在 0.045 以上？低于 0.04 用八股句式补上来
