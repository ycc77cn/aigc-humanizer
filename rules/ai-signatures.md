# AI 句式签名清单（体检用）

> Step 2 逐段体检时对照本清单标记命中项。命中越多，该段改写优先级越高。
> 分四层：词汇层、结构层、修辞层、统计层。
> 清单为全量覆盖：AI 生成文本的已知签名形态尽列于此，不在表外找毛病。

## 一、词汇层（高危连接词与套话）

以下词汇在 LLM 输出中出现频率显著偏高，命中即标记：

- 连接类：此外、同时、与此同时、不仅如此、综上所述、值得注意的是、总而言之
- 递进类：不仅…还…、既…又…、进一步、从而、进而
- 框架类：作为…的体现、见证了…、标志着…、是…的重要一步
- 归因类：专家认为、行业报告显示、业内人士指出、多方数据表明（无具体来源）
- 来源堆砌：罗列媒体名 / 平台名 / 粉丝量撑权威（"被XX、XX和XX引用"），
  只列名不给具体内容
- 残留类：聊天式协作残留（"希望这对您有帮助""请告诉我"）、
  知识截止免责（"截至X日期""基于可用信息"）、
  谄媚语气（"好问题！""您说得完全正确"）
- 高频 AI 名词偏好：赋能、闭环、深度融合、一体化能力、提质增效、新范式

## 二、结构层（句式形态）

- 三段式排比：三项并列、三个形容词修饰（"服务效率、管理水平和应急响应能力"）
- 四字工整并列：连续多个四字动宾结构（"跌倒预警分析、睡眠质量监测"）
- 对仗短句："护理员招不来，也留不住"式两两相对
- 金句收尾：段落最后一句是可摘抄的漂亮话（"大有可为"）
- 话题前置：短句倒装开头（"跌倒检测，毫米波雷达是现成的"）
- 总-分-总：每段"引入→展开→拔高收尾"的完美闭环
- 尾缀式肤浅分析：句末挂解释性分句（"…，确保了…，反映了…，彰显了…"），
  删掉不伤主旨的，全是
- 公式化"挑战与展望"段：先罗列挑战、再展望拔高，中间没有具体事实
- 系动词回避：用"作为…的证明 / 体现 / 提醒"绕开"是"字
- 虚假范围："从X到Y"，但 X 与 Y 根本不在同一尺度上
- 句长高度均匀：每句长度接近，节奏感过于稳定

## 三、修辞层（装饰成分）

- 成语与四字格：摇身一变、顺理成章、推陈出新、游刃有余（论文语料中反而稀少）
- 口语词混入正式文本：搭把手、省心、路子、数出
- 破折号插入语：——插入的强调性成分——
- 修辞性设问、感叹
- 引号强调："科技感"、"含金量"式标新立异的引号词
- 宣传腔：充满活力的、令人叹为观止、必游之地、坐落于…的中心、开创性的
- 过度限定："可以潜在地可能被认为""在一定程度上或许"
- 通用积极结论："未来可期""激动人心的时代""迈出重要一步"式收尾
- 格式装饰（正文内）：
  - 用粗体强调关键词
  - 内联标题式列表（**X:** 后接一句展开）
  - emoji 点缀
  - ASCII 直引号包中文（"养老"→机器与翻译腔痕迹，中文正字法用全角弯引号）

## 四、统计层（量化指标，改写后必须复核）

| 指标 | AI 形态 | 人类论文语料形态 |
|---|---|---|
| 的字密度（自然落点，去空白总字符含标点口径） | < 0.03 | 0.045 ～ 0.065 最佳，0.03 ～ 0.09 正常 |
| 同义词循环 | 频繁（同一对象换 3 种说法） | 几乎没有，同词连用 |
| 句号内逗号数 | 1 ～ 2 个 | 3 ～ 5 个（流水长句） |
| 句长方差 | 小（均匀）或刻意交错 | 大或整体偏长 |
| 修辞成分密度 | 高 | ≈ 0 |

## 体检输出格式

对每段输出一行记录：

```
[段号] 命中：词汇层(同时/从而) 结构层(三段式) 统计层(的密0.02)
       不可动：2.9亿、21%、60岁、颐养通、毫米波雷达、RAG
```

用户报告含逐句标红时，标红句子单列优先队列，先改标红句，再处理体检命中段。
